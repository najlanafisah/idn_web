# IDN Boarding School Website

A website introducing IDN Boarding School, created as my first final project during my early web development journey.

The project presents the school's identity, learning approach, student programs, and achievements through a dedicated website. It represents my early experience in building a website using HTML and CSS.

## Features

- **School Introduction:** Presents the identity and overview of IDN Boarding School.
- **Project-Based Learning:** Introduces the school's project-based learning approach.
- **School Information:** Highlights the school's educational environment and learning programs.
- **Student Activities:** Showcases various student programs and activities.
- **Achievements:** Displays school achievements and accomplishments.
- **Visual Interface:** Uses images, illustrations, and styled sections to present information.

## Tech Stack

- **HTML5:** Website structure and content
- **CSS3:** Styling, layout, and visual presentation
- **JavaScript:** Interactive website elements

## Getting Started

### Prerequisites

- A modern web browser
- Git
- A code editor, such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/idn_web.git
   ```

2. Navigate to the project directory:

   ```bash
   cd idn_web
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
